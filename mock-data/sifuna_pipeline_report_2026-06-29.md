## Methodology note (read first)
This is the first report this project has produced by actually running the full automated pipeline end-to-end against live data, rather than hand-assembling one from web search. Concretely, in this run:
- **Ingestion**: `SocialCrawlConnector.fetch()` hit SocialCrawl's live brand-mentions and native-social-discovery endpoints (TikTok, YouTube, LinkedIn, Twitter, web/news) with the real API key and returned **77 raw mentions**.
- **Cleaning + entity linking**: deduplication and strict on-topic entity matching (text must actually reference "Sifuna" / an approved alias) cut that to **30 mentions** that the pipeline judged genuinely about him — this is a feature, not data loss: it's the difference between "appeared in a feed near his name" and "is actually about him."
- **Sentiment**: scored per-mention by the engine's real sentiment model (HuggingFace pipeline, with Anthropic LLM as configured fallback).
- **Influence ranking & executive summary**: computed/generated live by the engine's influence-scoring module and Anthropic LLM respectively — not pre-written.
- **One real bug found and fixed along the way**: SocialCrawl's LinkedIn endpoint now returns `author` as a nested profile object (`{name, url, avatar, ...}`) instead of a plain string — a recent API change the team had flagged. The connector was crashing on this; fixed in `socialcrawl_connector.py` so LinkedIn author names map correctly (e.g. "Benard Omukuyia" instead of a raw dict).
- **One known gap**: Neo4j isn't reachable in this sandbox, so `network_insights.top_users` is empty this run — the graph-relationship layer (who-amplifies-whom) didn't run, even though everything else (Postgres, sentiment, influence, LLM summary) did. Narrative clustering also returned no distinct cluster this run — at 30 mentions spread across 7 months, the texts are too topically scattered (ouster fight, cost-of-living remarks, succession politics, birthday post) for the clustering threshold to group them into a named "narrative" yet; that will sharpen once ingestion runs on a tighter, more recent window.
